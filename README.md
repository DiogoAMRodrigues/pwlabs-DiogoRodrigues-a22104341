# Web Programming — Lab Work

Coursework for *Programação Web*, BSc Computer Engineering, Universidade Lusófona (2023). Four labs building up from static markup to animation and media, written in plain HTML, CSS and JavaScript with no frameworks.

Kept public as a record of early coursework — this is where I started with web development, not where I ended up.

## Labs

**Lab 1 — Semantic markup and multi-page structure**
A small tourism site covering landmarks in Ulm, Germany: the Münster, Rathaus, Metzgerturm, Schiefes Haus, Fischerviertel and the old Gefängnis. Focused on document structure, navigation between pages, tables and lists.

**Lab 2 — HTML5 features and interactivity**
HTML5 elements and CSS layout, plus an interactive quiz page driven by JavaScript.

**Lab 3 — Images and layout**
Three layout variants over the same content, working with image formats and page composition.

**Lab 4 — Animation and media**
CSS animation, a parallax scrolling page, and embedded video.

## Running it

Static files with no build step — open `index.html` in a browser, or serve the directory:

```bash
python -m http.server 8000
```

## Stack

HTML5, CSS3, vanilla JavaScript. No frameworks, no dependencies.
